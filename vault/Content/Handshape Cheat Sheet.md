# Handshape Cheat Sheet (UI content)

The 12 entries of `HANDSHAPES` in `js/signs.js`, shown at the bottom of the Routines tab ([[App Layout and Screens]]). These are *teaching* labels for the parent. They are **not** the same list as the shapes the camera detects ([[Handshape Detection]]).

| Name | Description (shortened 2026-10-31 at Ramani's request; example signs dropped) | Photo |
|---|---|---|
| Flat-O | Fingertips touch the thumb | No drawing (none in the Commons series) |
| C | Curved like a C | Commons drawing (public domain) |
| 5 (open) | All fingers spread | No drawing (none in the Commons series) |
| A | Fist, thumb on the side | Commons drawing (public domain) |
| S | Fist, thumb in front | Commons drawing (public domain) |
| Claw | Fingers spread and bent | No drawing (none in the Commons series) |
| Y | Thumb and pinky out | Commons drawing (public domain) |
| W | Three fingers up | Commons drawing (Sign language W.svg) |
| K | Two up, thumb between | Commons drawing (public domain) |
| T | Thumb under the index | Commons drawing (Sign language T.svg) |
| ILY | Thumb, index, pinky up | No drawing (none in the Commons series) |
| Index | Pointer finger up | No drawing (none in the Commons series) |
