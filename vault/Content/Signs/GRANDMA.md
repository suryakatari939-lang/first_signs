# GRANDMA

Routine: [[Family]] · app id `grandma` · defined in `js/signs.js` (`SIGNS` + `CHECKS`)

## How to sign it (shown to the parent)
| | |
|---|---|
| **Hand** | Open 5-hand, as in MOM. |
| **Where** | Starts with thumb on chin. |
| **Move** | Move forward in two small hops. |

**Remember it (hook):** MOM, one generation further out.

**Use it for real (`say`):** Teach Grandma too. More signers means more language.

## What the camera coach checks
`CHECKS.grandma` = `{ hands:1, shape:["5","flat"], at:"chin", ref:"thumb", move:["away","repeat"] }`

- **Hands needed:** 1
- **Accepted handshapes:** open 5-hand, flat hand → see [[Handshape Detection]]
- **Location:** at the chin (tracked point = `thumb`) → see [[Zones and Body Landmarks]]
- **Movement (any one passes):** `away` (move the hand out, away from the face); `repeat` (do the movement twice (tap, tap)) → see [[Movement Detection]]
