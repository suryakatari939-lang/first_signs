# Glossary

**ASL** — American Sign Language. **Gloss** — a written label for a sign in CAPITALS (e.g. ALL DONE). **Dominant hand** — the hand you write with; "one hand" in the app means this one.

**Handshape / Location / Movement** — the three components the coach checks ([[Camera Coach Overview]]). (Real ASL also has palm orientation and non-manual markers like facial expression; the app only mentions them in text.)

**Non-manual markers** — facial expressions/eyebrows; yes/no questions use raised eyebrows.

**Handshapes used in the app:** Flat-O, C, 5 (open), A, S, claw, Y, W, K, T, ILY (I-love-you), index — [[Handshape Cheat Sheet]], detection in [[Handshape Detection]].

**Fingerspelling** — spelling a word letter by letter with the manual alphabet; used for names, places and words without their own sign ([[ABC Screens]]).

**Easy-word lesson** — one of 9 steps that teach new letters and then practise short words made only of letters learned so far ([[Easy Word Lessons]]).

**Routine** — a group of signs tied to a daily moment ([[Routines and Signs Overview]]).

**Mission** — the single "use it for real today" sign on [[Today Screen]]. **Real moment** — one tap on "We used it" (`S.used`).

**Box / Leitner** — spaced-repetition level 0–6 for a sign; **due** = review time has arrived ([[Spaced Repetition]]).

**Known / Learning / New** — sign status: box ≥ 2 / has card but box < 2 / no card.

**Recall vs Pick** — the two practice modes ([[Practice Screen]]).

**Coach** — the global `Coach` object in `js/camera.js`. **Check / CHECKS** — per-sign camera target ([[CHECKS Format]]). **Zone** — region of the face/body ([[Zones and Body Landmarks]]). **F** — face width, the distance unit for all geometry. **Ref point** — the hand point tested against the zone (tips/index/thumb/center).

**MediaPipe Holistic** — Google's combined face + pose + hands landmark model ([[MediaPipe Holistic Vendor Bundle]]).

**Signing Savvy** — external ASL video dictionary, cited as a source for the ABC tab. (The old "Watch it signed" links to it were replaced by in-app hints.)

**Early intervention** — local services for deaf/hard-of-hearing infants and toddlers; the app recommends joining them.

**TSA** — Technology Student Association; this is the Software Development competition entry ([[Project Overview]]).
